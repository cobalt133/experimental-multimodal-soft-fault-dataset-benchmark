# QoT and labels

The 3355-capture primary cohort has five commanded-setting diagnosis labels. Normal includes nominal 75-GHz WSS filtering; bandwidth narrowing uses 70, 65, 60 and 55 GHz. Center-frequency offset is a separate label.

The 2224-capture low-BER cohort requires accepted offline QoT annotation and (BER_X+BER_Y)/2 < 0.024. The 0.024 value is a reference pre-FEC threshold associated with 20% overhead SD-FEC, not measured post-FEC performance. QoT acceptance requires successful processing, finite BER/EVM per polarization and their means, and BER_X<0.45 and BER_Y<0.45. Of 3355 captures, 2693 pass; 94 have unsuccessful processing and 568 fail the polarization-BER check. Missing/unaccepted QoT does not remove finite waveform features from full-cohort classification.

The 32 input columns are explicitly enumerated in feature_columns.json. QoT, condition metadata and labels are not signal-feature classifier inputs. The archived 34-descriptor schema includes two additional mean-intensity descriptors that are not used in the 32-input references. The 2048 temporal-array positions are uniform indices across one capture, not consecutive decoded symbols. PSD uses three log-spectral views and dB-domain pooling; it is not calibrated dBm/Hz. Raw acquisition and private receiver DSP are not distributed here.

The EVM columns report -20*log10(EVM_RMS), with normalized symbol-error RMS referenced to the ideal constellation RMS amplitude; larger is better. EVM_percent=100*10^(-reported/20). The mean EVM column averages the two reported dB values, not linear error energies. The Q columns report 20*log10(sqrt(2)*erfcinv(2*BER)), a BER-derived equivalent Q-factor. Infinite/invalid Q values are unavailable, not zero; a Q mean averages finite polarization values only. QoT validity does not require finite Q, so zero measured BER can coexist with unavailable derived Q. Per-polarization BERs are measured by Gray-QAM demodulation and bit comparison; the reported mean is an unweighted arithmetic polarization mean, not a bit-count-weighted rate when effective lengths differ.
